# 邮差 剧情推进开发版 Unity2022

文档用途：给程序拆任务、对接资源、检查剧情推进状态使用。

来源文档：`D:/下载/邮差（创意案_已添加对话字幕编号）.md`

整理原则：

- 保留原剧情与对白，不改核心设定。
- 将叙事文本改为“阶段 -> 任务 -> 触发 -> 交互 -> 演出 -> 完成条件”的开发结构。
- 对程序更关心的内容单独标注：输入限制、空气墙、UI界面、道具状态、场景切换、音效/演出、资源需求。
- 目前剧情为单结局循环反转结构，不需要多结局分支。

---

## 1. 核心设定

### 1.1 玩家身份

玩家扮演新到朝雾町的夜班邮差，负责 `400-410号` 的凌晨投递与傍晚收件。

### 1.2 异常对象

异常核心是 `410号` 与邮局后仓的 `410柜子`。

410号长期无人居住，但仍保留在邮局投递名单里。它会通过信件、纸条、照片、包裹提前记录玩家将要发生的行为，并逐步把玩家引向“最终投递”。

### 1.3 结局结构

DAY6 结尾玩家完成最终投递后进入“交接处”，回到邮局前台内侧，成为新局长。开场对白闭环：

> 喂，小子，我说话时候别走神。

## 2. 场景与系统清单

### 2.1 场景需求

| 场景 | 用途 | 关键对象 |
| --- | --- | --- |
| 邮局前台 | 局长对话、便签、电话、任务领取 | 局长、前台桌、电话、分拣架入口 |
| 邮局休息区 | 起床、睡觉、电脑/手机调查 | 床、旧电脑或手机 |
| 邮局分拣区 | 领取投递件、410格子掉纸条 | 400-410分拣格、投递包 |
| 邮局后仓 | 410柜子、包裹回收、惊吓 | 后仓门、410柜子、黑袋 |
| 街区 | 400-410投递/收件 | 信箱、门牌、410号门、宠物门 |
| 交接处 | 结局场景 | 门、纸条、邮局前台复现 |

### 2.2 全局系统需求

| 系统 | 说明 |
| --- | --- |
| 任务系统 | 支持主任务、任务更新、任务完成提示。 |
| 对话系统 | 使用 D 编号管理局长/电话/结尾对白。 |
| 字幕系统 | 使用 S 编号管理玩家自言自语与提示。 |
| 交互系统 | 便签、信件、照片、包裹、信箱、柜子、床、电话、电脑。 |
| 道具检视 UI | 信件、照片、包裹、纸条、标签需要可读界面。 |
| 时间段切换 | 凌晨、傍晚、黑屏入睡、黑屏醒来。 |
| 路径阻挡 | 未满足任务前阻挡去 410 或返回邮局。 |
| 演出系统 | 黑屏、音效、物体掉落、信箱弹开、手伸出、跳脸。 |
| 存档/进度 | 至少记录当前 Day、时间段、任务节点、关键道具状态。 |

### 2.3 常用对象状态

| 对象 | 状态示例 |
| --- | --- |
| 信箱 | 可投递、可收件、关闭、弹开、掉出纸条/包裹、不可打开。 |
| 410号门 | 无回应、门内敲击、宠物门开启、黑手出现。 |
| 410柜子 | 空、可放入、需关闭、发出敲击、内部漆黑、出现手印、跳脸。 |
| 电话 | 未响、响铃、可接听、接听后挂断、被局长阻止。 |
| 床 | 可休息、触发黑屏与时间推进。 |
| 投递包 | 存放当天投递件，DAY6 改为黑色袋子。 |

## 3. 编号规范建议

### 3.1 任务节点编号

建议格式：`D{Day}_{Time}_{Step}`

示例：

- `D02_AM_010_领取投递件`
- `D04_PM_040_回收410退回包裹`
- `D06_AM_080_最终投递`

### 3.2 文本编号

现有剧情已包含：

- 对话：`D001-D011`
- 字幕：`S001-S096`

开发时建议单独维护一张文本表，字段至少包含：

| 字段 | 说明 |
| --- | --- |
| text_id | 例如 S001、D001_01 |
| speaker | 局长、玩家、电话、系统 |
| content | 正文 |
| trigger_node | 触发节点 |
| skippable | 是否可跳过 |
| voice | 是否需要配音，当前可为空 |

## 12. 程序推进用任务拆分建议

### 12.1 推荐开发顺序

1. 先跑通 `DAY0-DAY1` 的基础循环：醒来、接任务、取件、投递、回收、睡觉。
2. 再接入 `DAY2` 的核心异常链：410信掉落、偷看信、照片、410信箱回执、后仓柜。
3. 然后补 `DAY3` 的论坛调查 UI，作为节奏缓冲。
4. 再实现 `DAY4-DAY5` 的包裹、黑手、柜子惊吓。
5. 最后实现 `DAY6` 与结局，避免早期过度绑定终局演出。

### 12.2 每天最小可验收标准

| Day | 最小可验收 |
| --- | --- |
| DAY0 | 能对话、睡觉、进入DAY1 |
| DAY1 | 能完成一次普通投递和一次普通收件 |
| DAY2 | 能完成410信件偷看、照片、投递、后仓包裹、电话 |
| DAY3 | 能阅读论坛3帖，傍晚能触发后仓污痕和敲击 |
| DAY4 | 能完成410信+包裹投递、宠物门黑手、退回包裹 |
| DAY5 | 能完成错放包裹、后仓跳脸、睡前纸条电话 |
| DAY6 | 能完成黑袋、最终投递、交接结局 |

### 12.3 资源需求清单

| 类型 | 资源 |
| --- | --- |
| UI文本 | 便签、信件、纸条、论坛帖子、照片背面、包裹标签 |
| 3D道具 | 普通信件、410信、普通包裹、410包裹、黑袋、电话、便签、照片 |
| 场景物件 | 400-410信箱、410门、宠物门、分拣架、410柜子、床、电脑/手机 |
| 特效 | 雨、黑屏、视野边缘变暗、轻微画面抖动、跳脸瞬间黑屏 |
| 音效 | 闹钟、呼吸、雨声、信件掉地、纸张掉落、电话铃、柜内敲击、门内敲击、宠物门声、跳脸音效、黑袋沙沙声 |
| 动画 | 信箱开合、纸条掉落、包裹拖入门内、黑手伸出/贴门、柜门开合、玩家坐下视角移动 |

### 12.4 容易出问题的状态点

| 风险 | 建议 |
| --- | --- |
| 任务跨 Day 切换混乱 | 每次睡觉前写入下一 Day 与时间段，黑屏结束后读取并刷新任务 |
| 410相关道具重复出现 | 每个节点结束后标记道具已领取/已投递/已回收 |
| 玩家提前去410破坏节奏 | 按任务节点启用空气墙或软阻挡 |
| 柜门忘记关闭 | 后仓出口检查柜门状态，不满足则显示 S023 |
| 电话事件漏触发 | 电话应绑定任务节点，不建议用随机触发 |
| 论坛 UI 与主线脱节 | 三个帖子全部阅读后才允许关闭并推进“休息” |
| DAY6 返回邮局 | 使用画面压迫、减速和音效作为软阻挡，必要时加硬阻挡 |
